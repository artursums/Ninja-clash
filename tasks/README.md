# Tasks — Detailed Dev Prompts

One file per task: `DEV-NNN.md`. Each file is a self-contained prompt you can
paste into a fresh Claude Code session to start that task.

- Index of all tasks lives in [`../future-devs.md`](../future-devs.md).
- Create new entries with the `/future-dev <idea>` skill.
- Numbering is sequential and never reused (DEV-001, DEV-002, …).

## Task file shape

```markdown
# DEV-NNN: [Title]

**Status:** 🔵 Backlog   **Priority:** P2   **Area:** gameplay
**Created:** YYYY-MM-DD

## Idea (raw)
[User's original idea, verbatim]
```
