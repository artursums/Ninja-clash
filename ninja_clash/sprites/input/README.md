# Input graphics

Selected SVG assets from [Kenney Input Prompts 1.5A](https://kenney.nl/assets/input-prompts), licensed CC0.

Controller diagrams use a cropped view box and the game's dark ink / ivory palette. Small menu buttons are added to the simplified controller silhouettes to anchor their callouts. Button artwork is unchanged; rasterization size is increased for clean scaling. The original license is included.
