# Presentation snapshots

- `character-design-2026-09-12/`: original character, costume, weapon and effect assets, integration scripts, checksums and restoration instructions.
- `arena-960x540-2026-09-12.tar.gz`: arena geometry, bounds, atmosphere and previews before the compact 880 × 495 revision.
- `compact-character-study-2026-09-12.tar.gz`: the five compact base-design alternatives and their pose source, retained for comparison. They are not used by the game.
- `character-study-2026-09-12.tar.gz`: the taller character study, its atlases and pose source, retained for comparison. It is not used by the game.

Archive paths are relative to the repository root. Extract into a separate directory to inspect without replacing working files. Save current changes before restoring over the project, then reimport in Godot.
